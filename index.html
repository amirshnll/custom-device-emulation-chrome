From preset to DevTools

  1. Open Chrome DevTools, then toggle the device toolbar.
  2. Open Dimensions → Edit → Add custom device.
  3. Enter the name, width, height and DPR shown above. Choose Mobile or Desktop as appropriate.
  4. Optionally copy the user agent, then click Add and select your device.

Copying settings does not import them automatically into Chrome.
